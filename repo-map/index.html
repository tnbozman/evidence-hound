    Repository map¶

    Every folder in this repository, why it is there, who uses it, and whether it stays. A test (RepoMapTests) fails when a folder is added without a row here, or a row names a folder that no longer exists, so add the row in the same change as the folder.

    Users: person (a GRC team member or contributor reads or edits it), agent (the person's coding agent reads it), hound (the CLI reads or embeds it at run time), CI (a workflow or test runs it), release (it ships in a package or image).

    Verdicts: keep; merge into the folder named; remove, with the reason. A verdict that removes something a person may rely on waits for the maintainer (s19-02).

    Reviewed 2026-11-26 (s19-01).

    tools/ Pinned Python and Node tools for the docs site, changelog and Markdown lint. CI keep. A compiled Python file committed under tools/docs/hooks/__pycache__/ is removed and ignored.
