# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: **Security > Report a vulnerability** on this repository. Do not open a public issue.

Include what you found, how to reproduce it, and the impact you expect. You will get an acknowledgement within 5 working days.

## Supported versions

Only the latest release receives security fixes.

## Scope

In scope: this repository's code, container images, release artifacts and reference deployment.
Out of scope: CISO Assistant itself (report to its maintainers) and vendor APIs the collectors call.

## Handling data

Never include real organisation names, tenant identifiers, hostnames, evidence or credentials in reports, issues or pull requests. Use fictional examples.
