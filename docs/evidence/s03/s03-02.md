# s03-02 Secret provider

**Status:** Done (2026-11-21).

## What was done
- Core port `ISecretProvider.Resolve(SecretReference) -> Result<Secret>`. `Secret` holds the value privately; `ToString()` returns `***`, and only `Reveal()` hands the value over.
- Adapters in `EvidenceHound.Runtime.Secrets`: `EnvironmentSecretProvider` (a name lookup; empty counts as missing), `FileSecretProvider` (reads the file, trims one trailing `\n` or `\r\n`), and `CompositeSecretProvider`, which picks the provider by scheme. `CompositeSecretProvider.Standard` wires both.
- A missing secret is `secret.missing` with the message `Secret <reference> could not be resolved: <why>.`: the reference, never a value.
- `SecretCheck.Missing(config, provider)` resolves the CISO Assistant token and every collector secret once each. `hound config validate --check-secrets` uses it, so an operator can check a deployment's secrets before the first run. In the CLI, `env:` reads .NET configuration (environment variables).

## Deviations
- The problem code is `secret.missing` (dotted like every other code) rather than `secret_missing`.
