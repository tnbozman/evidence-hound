# s03-04 Runner pipeline

**Status:** Done (2026-11-21).

## What was done
- `Runner` (Runtime) runs each selected collector on its own: the `CollectStep` from s03-03, then the pure steps from s01 (evaluate, map, plan) on the collector's results, then publishing through the s02 sink. A crash becomes `collector.crashed`, so one collector failing never stops the others.
- Only owned requirements are published: a requirement is updated only when every check it maps to was reported by this collector, so one collector never overwrites another's result with `not_assessed`.
- Evidence IDs are scoped by collector (`example-fake/mfa-users.json`). The functional run found that CISO Assistant rejects a second evidence with the same name in a folder, so the new pure `EvidenceNames.For` names evidence by its ID when the ID ends with the file name, and `file name (ID)` otherwise.
- `hound run --config <file> [--only <name>] [--dry-run] [--no-publish]` prints a JSON summary per collector. `HOUND_CA_URL` overrides the configured URL and the token resolves through the secret provider. Exit codes: 0 all ok, 1 any collector failed, 2 usage (unknown `--only`), 3 configuration or secrets.
