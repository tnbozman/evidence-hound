# s02-03 Publisher

**Status:** Done (2026-11-21)

## What was done
- `src/EvidenceHound.Core/Publishing/Publisher.cs`: `PublishAsync` sends the plan in order and returns a `PublishReport` (planned, sent, skipped, failed, with per-item problems). `Publisher.DryRun` builds the report without any client.
- Evidence ref IDs from the plan are resolved to CISO Assistant evidence IDs as each upload succeeds; a requirement citing evidence that failed fails with `publish.evidence_unresolved`.
- Idempotent: an upload is skipped when the evidence's latest revision `attachment_hash` equals the recorded SHA-256, and a changed file becomes a new revision of the same evidence. File content is checked against the recorded hash before upload (`evidence.hash_mismatch`).
- `hound publish --config --checks --evidence-dir [--dry-run]` with `HOUND_CA_URL` and `HOUND_CA_TOKEN`; it prints the JSON report, logs each failed item, and exits 4 if any item failed. Guide: [`docs/publishing.md`](../../publishing.md).

## Deviations
- `--checks` and `--evidence-dir` replace `--plan`: the command plans itself, because planning is pure and a dry-run plan carries no file content.
- The URL and token come from environment variables, not the config file, until s03's config schema.
