# s02-04 Optional Kafka transport

**Status:** Done in code and CI (2026-11-21). The end-to-end dispatcher check needs the maintainer (steps below).

## What was done
- `IAuditUpdateSink` in core with two adapters: `RestSink` (default, wraps the publisher) and `KafkaSink` in `src/EvidenceHound.Transport.Kafka`, the only project that references Confluent.Kafka. It writes dispatcher JSON to the `observation` topic with an idempotent producer and base64 file content.
- `HOUND_TRANSPORT=kafka` with `HOUND_KAFKA_BOOTSTRAP_SERVERS` chooses it; anything other than `rest` or `kafka` is `config.transport_unknown`.
- Compose profile `kafka` (`make ca-up-kafka`) adds Redpanda and the dispatcher, built from the `v4.3.4` release tag because upstream publishes no image.

## Deviations
- Requirement messages leave out `evidences`: the dispatcher passes values straight to PATCH and cannot turn evidence ref IDs into IDs.
