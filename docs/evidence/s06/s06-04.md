# s06-04 Change-only publishing, traced to the run

**Status:** Done (2026-11-21).

## What was done
- Planning: `AuditPlanner.PlanChanges(targets, evidence, controlStatuses, current, runId)` (pure) plans against what CISO Assistant already holds (`CurrentState`: each target audit's rows and selected groups, evidence with its latest SHA-256, applied control statuses).
  - A row's state is its result, the outcome of each check behind it and the hashes of its evidence (`RowState.Fingerprint`, 16 hex characters of a SHA-256). Timestamps are not part of it.
  - Each written observation ends with a marker, `[hound run <run id> state <fingerprint>]`. A row whose marker shows the desired state and whose result and evidence still match is not sent. If the marker matches but the result or evidence differ, someone edited the row: it is written back and reported as `publish.drift_corrected`, naming the row and the old and new values.
  - Evidence whose latest hash in CISO Assistant matches is linked by its known ID and not uploaded. Applied controls whose status already matches are not sent.
  - Rows outside the audit's selected groups are neither sent nor counted. A requirement with no known row falls back to the publisher's lookup.
- Reading state: `ClientStateSource` lists each audit's rows (`requirement-assessments/?compliance_assessment__ref_id=…`, paged by `limit` and `offset`), finds evidence and its latest revision hash, and reads applied control statuses. Anything it cannot read is left out, so that item is sent. Over Kafka there is no state (`NoCurrentState`).
- Run ID and history: each run has an ID (`yyyyMMddTHHmmssZ`, UTC). `hound run` appends one line per audit to `_history/<audit>.jsonl` in the evidence store (date, run ID, changed, unchanged, drift), except on `--dry-run` or `--no-publish`.
- Reports: the run report has `run_id`, and each collector has `changes` per audit and `drift`. `hound status` adds an audit table (last run, run ID, changed, unchanged, drift). `hound plan` without `--dry-run` reads CISO Assistant and prints only what differs.
- Docs: `docs/running.md` ("Only changes are sent", the status audit table) and `docs/publishing.md`.
