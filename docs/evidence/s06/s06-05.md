# s06-05 CISO Assistant configuration inventory

**Status:** Done (2026-11-21).

## What was done
- `docs/ciso-assistant-configuration.md` lists each CISO Assistant object type: configuration or runtime data, whether `hound` manages it in s06, later or never, its endpoint, its stable key, and how create, update, lock and delete behave. It answers Q1 to Q6 with evidence from v4.3.4.
- `scripts/ca-inventory.sh` probes a CISO Assistant instance for those answers and saves its OpenAPI schema (1,805 paths) and a snapshot of the resources `hound` uses or s06 configures (341 paths). Every probe object is fictional (`hound-probe-*`, `EX-PROBE-*`) and is deleted again. The functional CI job runs it and prints `answers.json` and the snapshot in the step "Show the CISO Assistant inventory".
- `tests/fixtures/ciso-assistant/openapi-v4.3.4.json` is the committed snapshot. `ApiEndpoints.Used` lists the twelve endpoints the client calls, and a test fails when one of them leaves the snapshot.
