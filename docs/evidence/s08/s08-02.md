# s08-02 Sophos checks

**Status:** Done (2026-11-22). The end-to-end run against CISO Assistant is the functional test `SophosRunFunctionalTests`, which runs in CI's functional job.

## What was done
- **Collector** `sophos` (`SophosCollector`), registered as a built-in collector. It reads the tenant's endpoints and firewalls (s08-01), writes `endpoints.json` and `firewalls.json`, and reports four checks, each a pure function over the parsed lists:

| Check | Pass when | Otherwise |
| --- | --- | --- |
| `endpoint.protection.healthy_ratio` | At least `healthy_pass_percent` (95) of endpoints have overall health `good` | `partial` from `healthy_partial_percent` (80), else `fail`; no endpoints is `fail` |
| `endpoint.protection.tamper_protection_enabled` | Every endpoint reports tamper protection on | `fail`, counting endpoints off or not reported |
| `endpoint.protection.stale_agents` | Every endpoint was seen in the last `stale_agent_days` (14) | `fail`, counting stale or never-seen endpoints |
| `network.firewall.firmware_supported` | Every firewall's firmware version is, or is within, a version in `supported_firewall_firmware` (21.0.1 is within 21.0) | `fail`, listing unsupported versions; no firewalls is `not_applicable` |

- **Evidence privacy**: unless `include_identities: true`, host names, firewall names, serial numbers, IP and MAC addresses and the associated person are replaced by a short SHA-256 hash, and firewall locations are dropped. IDs, health, versions and timestamps stay.
- Settings: `client_id` and `supported_firewall_firmware` required, the rest optional with defaults. Secret: `client_secret` (required). A missing secret is `sophos.secret_missing`.
- Contract kit: `SophosCollectorContractTests` in the runtime tests, with a refused-token scenario.
