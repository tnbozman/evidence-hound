# s08-09 Guided setup in hound, and the local trial

**Status:** Done in CI (2026-11-22). The person's own run in their dev container is the start of s08-08.

## What was done
- Wizards in `hound`: `hound init <folder>` (a new organisation's compliance repo that validates as written), `hound add system`, `hound add control` and `hound add collector <type>` (settings from the collector's own description, secrets into a mode 600 file with `--secrets-dir`). Every question has an option and a default; `--yes` asks nothing; nothing is written unless the result validates. Edits keep the file's comments and indentation (`YamlEdit`).
- `make trial` keeps only the host checks (Docker, an already running CISO Assistant reused or ports checked, the runner image, the token file) and runs each `hound` command in a throwaway container on CISO Assistant's network.
- Defects found by the CI trial and fixed test-first: `make ca-up`'s seed step lacked the secret key (`00d224b`, `dd1706c`); clearing a control's priority or due date was left out of the PATCH, so every plan showed the same update and drift again (`0f2c380`, `ed3d7ee`).
- Guides: `docs/guided-setup.md`, `docs/tutorials/local-trial.md`.

## Functional check
In CI ([trial job](https://github.com/tnbozman/evidence-hound/actions/runs/44998421402/job/137134420701)): `make ca-up` started and seeded a fresh CISO Assistant 4.3.4, then `HOUND_TRIAL_YES=1 make trial` ran twice.

**First run:** preflight found the running CISO Assistant on `hound-ciso-assistant_default` and reused it; the image was built; `hound init /trial/repo` wrote Example Pty Ltd's repo (audit EX-E8-2027); `config validate`, `scope validate`, `scope plan --out` and `scope apply` of the saved plan; `hound add system` (Example backup service), `hound add control` (AC-BACKUP, linked to ISM-1511 and ISM-1515) and `hound add collector manual`; apply again; `hound manual upload` of the restore test record with an attestation; `hound run --only example-backup-restore-test` (1 check passed, its result published to EX-E8-2027) and `hound status`; then it stopped before Sophos.

**Second run:** every finished step was skipped (`Already built`, `Already written: repo/hound.yaml and repo/scope`, `already uploaded`), and the plan changed nothing:

```text
$ hound scope plan scope --config hound.yaml --out /trial/scope-plan.json
## Scope plan

0 to create, 0 to update, 0 to delete. 8 drifted.
```

The 8 drifted objects are the dev seed's own example objects (AC-MFA, two documents, three audits, two systems), which this new organisation's scope does not declare: expected, and said in the tutorial. The run after it reported `changed 0, unchanged 1` for EX-E8-2027. No token appears in the log: it is read from `/trial/secrets/ca_token`.
