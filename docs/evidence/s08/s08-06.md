# s08-06 Compliance impact in scope plans

**Status:** Done (2026-11-22).

## What was done
- `ComplianceImpact.Of` (pure, in the core): for each declared audit, the rows whose result the plan changes, with the requirement, title, strategy (the parent node), old and new result and why ("hand-written in the audit file" or "the unlisted rule"), regressions first, and the compliant count per selected group before and after. Rows the deployment's mappings compute are left out: their impact belongs to `hound plan`.
- The state reader also reads every held row of each declared audit, so the "before" counts are real.
- `hound scope plan` prints a "Changes to compliance" section after the change table, and `compliance[]` in JSON; `hound scope apply` reports it too. `docs/scope.md` shows an example.

## Functional check
In CI ([trial job](https://github.com/tnbozman/evidence-hound/actions/runs/44998421402/job/137134420701)) against a fresh CISO Assistant 4.3.4 seeded with the example compliance repo, `scripts/check-scope-plans.sh` copies the example repo, sets the hand-written ISM-1486 back from compliant to non-compliant, adds ISM-1485 as compliant, and plans:

```text
$ hound scope plan $WORK/repo/scope --config examples/example-essential-eight.yaml
exit 0
### Changes to compliance

**EX-E8-2026**: 2 result changes, 1 regression ⚠.

- Maturity Level One: 1 → 1 compliant of 48
- Maturity Level Two: 1 → 1 compliant of 107

|  | Requirement | Title | Strategy | Result | Why |
| --- | --- | --- | --- | --- | --- |
| ⚠ | ISM-1486 | Web browsers do not process Java from the internet. | UAH | compliant → non_compliant | hand-written in the audit file |
|  | ISM-1485 | Web browsers do not process web advertisements from the internet. | UAH | not_assessed → compliant | hand-written in the audit file |
```

The gain and the regression cancel out in both groups (1 → 1), and the regression is listed first and flagged.
