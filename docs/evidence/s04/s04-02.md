# s04-02 Contract test kit

**Status:** Done (2026-11-21).

## What was done
- New packable project `src/EvidenceHound.Collectors.Testing` (package `EvidenceHound.Collectors.Testing`, depends on `xunit.v3.extensibility.core`, `xunit.v3.assert` and `WireMock.Net`). Usage is in its [README](../../../src/EvidenceHound.Collectors.Testing/README.md).
- `CollectorContractTests<TCollector>` is an abstract xUnit class with six contracts: `DescribesAtLeastOneCheck`, `EmitsOnlyDeclaredCheckIds`, `EvidenceFilesCanBeHashed` (the runner's manifest accepts the files, content is the same on every read, cited files exist), `HonoursCancellation`, `ReturnsFailNotThrowsWhenCredentialsAreRefused` and `NeverLogsSecrets` (messages, structured values, scopes and exceptions at every level). Each failure message names the collector and what to change.
- `CollectorScenario` supplies settings, secret values and HTTP clients. By default there is no network (`OfflineHttpClients`). Declared secrets missing from a scenario get a made-up value, which the secret-logging contract checks. A collector that declares secrets must provide a `RefusedCredentials` scenario. One that declares none passes the credentials contract.
- `RecordedApi` is a WireMock.Net server that replays recorded response files or inline responses, and gives HTTP clients whose base address is the server.
- The fake collector passes the kit. It now honours cancellation, the one contract it broke. `ContractCoverageTests` fails if any collector registered by `AddBuiltInCollectors()` has no public contract test class.
- `CollectedEvidence.ReadAsync` is now the one way to read an evidence stream, used by both the runner and the kit.
- `Humanizer` is pinned to 3.0.10. WireMock.Net brings in Humanizer 2.14.1, whose locale packages pin Humanizer.Core 2.14.1, while JsonSchema.Net in Runtime.Tests needs Humanizer.Core 3.0.10. 3.0.10 is within the range WireMock's Handlebars helpers allow.
