- `Evidence.Create` requires a 64-character hex SHA-256 (stored lowercase), a non-blank ID, file name and media type, and a size of zero or more.
- `src/EvidenceHound.Core/Results/Validation.cs`: `Validation.Validate` builds a value only when every `Invariant` holds.
- A reflection test checks that no type or public member in `EvidenceHound.Core.Checks` mentions a framework.
