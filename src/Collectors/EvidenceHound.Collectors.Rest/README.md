# EvidenceHound.Collectors.Rest

The Evidence Hound rest collector: reads any REST API described by a YAML profile, builds evidence datasets and evaluates declarative checks.

It ships inside the `hound` CLI and the runner image; this package is for building and testing on top of it. Guide:
[docs/collectors/rest.md](https://github.com/tnbozman/evidence-hound/blob/main/docs/collectors/rest.md).
