# EvidenceHound.Collectors.VulnScan

The Evidence Hound vuln-scan collector: vulnerability scanner exports (Nessus v2 or mapped CSV) dropped in a folder become structured scan evidence.

It ships inside the `hound` CLI and the runner image; this package is for building and testing on top of it. Guide:
[docs/collectors/vuln-scan.md](https://github.com/tnbozman/evidence-hound/blob/main/docs/collectors/vuln-scan.md).
