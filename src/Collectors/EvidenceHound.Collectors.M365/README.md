# EvidenceHound.Collectors.M365

The Evidence Hound Microsoft 365 collector: read-only Microsoft Graph checks for identity, privileged access, device compliance and Office hardening.

It ships inside the `hound` CLI and the runner image; this package is for building and testing on top of it. Guide:
[docs/collectors/m365.md](https://github.com/tnbozman/evidence-hound/blob/main/docs/collectors/m365.md).
