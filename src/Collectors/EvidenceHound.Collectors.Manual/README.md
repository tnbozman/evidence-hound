# EvidenceHound.Collectors.Manual

The Evidence Hound manual-upload collector: export files dropped in a folder, optionally attested by their owner, become evidence and check results.

It ships inside the `hound` CLI and the runner image; this package is for building and testing on top of it. Guide:
[docs/manual-evidence.md](https://github.com/tnbozman/evidence-hound/blob/main/docs/manual-evidence.md).
