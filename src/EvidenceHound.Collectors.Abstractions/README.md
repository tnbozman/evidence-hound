# EvidenceHound.Collectors.Abstractions

The interface an [Evidence Hound](https://github.com/tnbozman/evidence-hound) collector implements (`ICollector`), its description of
checks, settings and secrets, and its registration. Start from the template: `dotnet new install EvidenceHound.Templates`, then
`dotnet new hound-collector -n Example.Widget`. Guide:
[write a collector](https://github.com/tnbozman/evidence-hound/blob/main/docs/tutorials/write-a-collector.md).
