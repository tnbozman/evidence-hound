# EvidenceHound.Core

The domain types and pure logic of [Evidence Hound](https://github.com/tnbozman/evidence-hound): check results, evidence, requirement
results and problems. Collector authors use it through `EvidenceHound.Collectors.Abstractions`; see
[write a collector](https://github.com/tnbozman/evidence-hound/blob/main/docs/tutorials/write-a-collector.md).
